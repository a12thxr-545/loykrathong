# ประเพณีลอยกระทง วันเพ็ญเดือนสิบสอง (Loy Krathong Festival)

เว็บแอปพลิเคชันจำลองประเพณีลอยกระทงออนไลน์ ให้เด็กสองคนร่วมลอยกระทงลงสู่สายน้ำในคืนวันเพ็ญเดือนสิบสอง (๒๔ พฤศจิกายน) เพื่อขอขมาพระแม่คงคาและอธิษฐานขอพรเพื่อความเป็นสิริมงคล ออกแบบด้วยสไตล์ไทยร่วมสมัย เรียบหรู สะอาดตา ไม่ใช้ emoji (ใช้ SVG icons และป้ายข้อความประณีตแทน) พร้อมระบบ **ฐานข้อมูลบันทึกคำอธิษฐานและข้อความ (Database Storage)**

---

## จุดเด่นและฟังก์ชันการใช้งาน

1. **ระบบฐานข้อมูลบันทึกคำอธิษฐานและข้อความ (Database Storage)**:
   - **บันทึกอัตโนมัติเมื่อปล่อยกระทง**: ทุกครั้งที่กดปล่อยกระทง ระบบจะบันทึกชื่อ, วันที่, เวลา, คำอธิษฐาน, ข้อความบันทึก และรูปแบบกระทงลงในฐานข้อมูลทันที
   - **ระบบฐานข้อมูลแบบสองชั้น (Dual-Tier Hybrid Database)**:
     - **SQLite Database (ฝั่ง Server)**: บันทึกข้อมูลลงฐานข้อมูล SQLite ในไฟล์ `data/wishes.sqlite` (หรือ `wishes.json`) เมื่อรันด้วย Node.js
     - **IndexedDB (ฝั่ง Client)**: บันทึกข้อมูลลงฐานข้อมูลในเบราว์เซอร์อัตโนมัติ ทำให้ใช้งานและบันทึกข้อมูลได้ 100% แม้เปิดผ่าน GitHub Pages หรือเปิดไฟล์ `index.html` แบบออฟไลน์
   - **สมุดบันทึกคำอธิษฐาน (Wishes Archive)**: มีปุ่ม "สมุดบันทึก" บนแถบเมนู เพื่อเปิดดูประวัติคำอธิษฐานทั้งหมดที่เคยบันทึกไว้ พร้อมวันที่และเวลา
   - **ส่งออกข้อมูล (Export JSON)**: สามารถกดปุ่มส่งออกข้อมูลคำอธิษฐานทั้งหมดออกมาเป็นไฟล์ JSON สำรองไว้ได้

2. **การร่วมลอยกระทงของเด็กสองคน**:
   - นำรูปถ่ายวัยเด็กของทั้งสองคนมาจัดวางอย่างลงตัว ทั้งบนหน้าแรก, บนตัวกระทง และที่ท่าน้ำริมตลิ่ง
   - **กระทงคู่เคียงข้าง**: กระทงของคนที่ 1 และคนที่ 2 ลอยเคียงคู่กันไปตามสายน้ำ โดยมีสายสิญจน์มงคลสีทองเชื่อมโยง หรือเลือกเป็นกระทงเดี่ยว
   - **กรอบภาพถ่ายขนาดเล็ก**: ปักภาพถ่ายของแต่ละคนไว้บนกระทงพร้อมธูปเทียนสว่างไสว

3. **การปรับแต่งกระทงตามประเพณี**:
   - ฐานกระทง: ใบตองพับ, กลีบบัวหลวง, ขนมปังรักษ์น้ำ, กาบกล้วยธรรมชาติ, วิจิตรศิลป์
   - ดอกไม้บูชา: บัวชมพู, ดาวเรือง, กล้วยไม้, มะลิสด, ดอกไม้รวม
   - เหรียญตามประเพณี: เหรียญทอง, เหรียญเงิน, หรือไม่ใส่เหรียญ
   - ธูปและเทียน: สามารถคลิกจุดเทียนหรือดับเทียนได้

4. **บรรยากาศสายน้ำยามค่ำคืน**:
   - พระจันทร์เต็มดวงนวลตา พร้อมเงาสะท้อนระลอกคลื่นบนผิวน้ำ
   - ทิวทัศน์ริมน้ำเจ้าพระยาและแสงไฟเทศกาลอบอุ่น
   - ปล่อยโคมลอยขึ้นสู่ท้องฟ้า พร้อมข้อความอธิษฐาน
   - จุดพลุเฉลิมฉลองเทศกาล (แบบทรงกลมและประกายดาวคลาสสิก)

5. **ภาพถ่ายที่ระลึก (Keepsake Card)**:
   - บันทึกภาพความประทับใจของเด็กสองคนและกระทงที่ลอยในคืนวันเพ็ญ
   - สามารถดาวน์โหลดไฟล์ภาพ PNG ความละเอียดสูงลงเครื่องได้ทันที

6. **ระบบเสียงดนตรีบรรเลง (Web Audio API)**:
   - สังเคราะห์เสียงบรรยากาศสายน้ำและระฆังแก้วกังวาน ไม่ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไฟล์เสียง

## วิธีเปิดใช้งาน

### วิธีที่ 1: รันด้วย Node.js Server (พร้อมฐานข้อมูล SQLite)
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
- ฐานข้อมูลจะถูกเก็บไว้ที่ `data/wishes.sqlite` อัตโนมัติ
- มี REST API รองรับ: `GET /api/wishes`, `POST /api/wishes`, `DELETE /api/wishes/:id`

### วิธีที่ 2: เปิดผ่านเว็บเบราว์เซอร์ทันที (ออฟไลน์ / GitHub Pages)
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานได้ทันที ระบบจะบันทึกข้อมูลคำอธิษฐานลงใน **IndexedDB** ภายในเครื่องโดยอัตโนมัติ
